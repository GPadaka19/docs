Every request on this page requires a [Bearer API key](/en/api/autentikasi).

## Exam endpoints

This page covers the endpoints that read exams. Creating and changing exams, tests and sessions through the API is described in [Exam Setup](/en/api/pengaturan-ujian), and questions are sent through the [Question Import API](/en/api/import-soal).

### Key exam fields

| Field | Description |
| --- | --- |
| `is_active` | Exam registration is open. |
| `is_locked` | The exam is locked (for example because it has been archived). A locked exam rejects participant registration through the API. |
| `is_hidden` | The exam is archived and hidden from participants. |
| `is_tiered` | Multi-level exam: tests in the next level open once the previous level is finished. |
| `is_auto_assign_session` | Registered participants are automatically placed in the earliest-created session of each test. If `false`, an admin assigns sessions in the admin panel. |
| `is_must_be_in_order` | Tests must be taken in order of `level`. |
| `is_force_complete` | A test must be finished without a break before the next one. |
| `is_show_score` | The final score is shown to participants in the CBT. It does not limit the scores available through the API. |
| `edition` | `standard` (Standard Exam) or `professional` (Professional Exam). It decides which credit participants use when they start, the maximum number of tests, and whether CAT and camera, screen and dual-monitor proctoring are available. |
| `final_score_type` | How the exam's final score is calculated from the test scores: `1` sum, `2` average. |
| `paid_type` | `1` free, `2` one-time payment, `3` paid per test, `4` paid per level. |

For tests (`exam_quizzes`), `exam_type` is `cbt`, `cat` or `manual`, `duration_minutes` is the test's working time, `score_type` is the scoring method, and the `is_*` fields are the test settings (see [Exam Setup](/en/api/pengaturan-ujian)). On a session, `question_bank_id` is the ID of the question package taken in that session.

<Accordion title="GET /exams — List exams">
  ### Parameters

  | Name | Location | Required | Type | Description |
  | --- | --- | --: | --- | --- |
  | `search` | Query | No | string | Searches the exam name or short name. |
  | `is_active` | Query | No | boolean | Filters by active status. |
  | `is_tiered` | Query | No | boolean | Filters multi-level exams. |
  | `start_from` | Query | No | datetime | Earliest start time, in ISO 8601 format; must be URL-encoded. |
  | `start_until` | Query | No | datetime | Latest start time, in ISO 8601 format; must be URL-encoded. |
  | `page` | Query | No | integer | Page number. Default `1`. |
  | `per_page` | Query | No | integer | Items per page, `1–100`. Default `25`. |

  ### Example request

  ```bash
  curl -X GET "https://app.indolat.com/api/v1/exams?search=Tes%20Masuk&is_active=true&page=1&per_page=25" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json"
  ```

<Accordion title="GET /exams/{exam}/registration-link — Self-registration link">
  Requires the **Exam Registration Page and Automatic Payment** add-on. If the add-on is not active, the request is rejected with status `403`. The returned link is a short link to the exam's self-registration page.

  ### Parameters

  | Name | Location | Required | Type | Description |
  | --- | --- | --: | --- | --- |
  | `exam` | Path | Yes | integer | Exam ID. |

  ### Example request

  ```bash
  curl -X GET "https://app.indolat.com/api/v1/exams/12/registration-link" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json"
  ```

  ### Example response

  ```json
  {
    "success": true,
    "message": null,
    "data": {
      "exam_id": 12,
      "registration_url": "https://app.indolat.com/link/aB3xZ"
    }
  }
  ```
</Accordion>
