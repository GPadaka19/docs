## Endpoint ujian

Halaman ini berisi endpoint untuk membaca ujian. Membuat dan mengubah ujian, tes, dan sesi lewat API dijelaskan di [Pengaturan Ujian](/api/pengaturan-ujian), sedangkan soal dikirim lewat [API Import Soal](/api/import-soal).

### Field penting pada ujian

| Field | Keterangan |
| --- | --- |
| `is_active` | Pendaftaran ujian dibuka. |
| `is_locked` | Ujian dikunci (misalnya karena diarsipkan). Ujian yang dikunci menolak pendaftaran peserta melalui API. |
| `is_hidden` | Ujian diarsipkan dan tidak tampil bagi peserta. |
| `is_tiered` | Ujian berjenjang: tes pada jenjang berikutnya terbuka setelah jenjang sebelumnya selesai. |
| `is_auto_assign_session` | Peserta yang didaftarkan otomatis ditempatkan pada sesi yang paling awal dibuat untuk setiap tes. Jika `false`, sesi ditentukan admin melalui panel. |
| `is_must_be_in_order` | Tes harus dikerjakan berurutan sesuai `level`. |
| `is_force_complete` | Tes harus diselesaikan tanpa jeda sebelum lanjut ke tes berikutnya. |
| `is_show_score` | Nilai akhir ditampilkan kepada peserta di CBT. Tidak membatasi nilai yang tersedia melalui API. |
| `edition` | `standard` (Ujian Standard) atau `professional` (Ujian Professional). Menentukan kredit yang dipakai saat peserta mulai, batas jumlah tes, serta ketersediaan CAT dan proctoring kamera, layar, dan dual monitor. |
| `final_score_type` | Cara menghitung nilai akhir ujian dari nilai tes: `1` akumulasi, `2` rata-rata. |
| `paid_type` | `1` gratis, `2` sekali bayar, `3` berbayar per tes, `4` berbayar per jenjang. |

Pada tes (`exam_quizzes`), `exam_type` bernilai `cbt`, `cat`, atau `manual`, `duration_minutes` adalah durasi pengerjaan tes, `score_type` adalah metode penilaian, dan field `is_*` adalah pengaturan tes (lihat [Pengaturan Ujian](/api/pengaturan-ujian)). Pada sesi, `question_bank_id` adalah ID paket soal yang dikerjakan pada sesi tersebut.

<Accordion title="GET /exams — Daftar ujian">
  ### Parameter

  | Nama | Lokasi | Wajib | Tipe | Keterangan |
  | --- | --- | --: | --- | --- |
  | `search` | Query | Tidak | string | Mencari nama atau nama singkat ujian. |
  | `is_active` | Query | Tidak | boolean | Filter status aktif. |
  | `is_tiered` | Query | Tidak | boolean | Filter ujian berjenjang. |
  | `start_from` | Query | Tidak | datetime | Waktu mulai minimum dalam format ISO 8601 dan harus di-URL-encode. |
  | `start_until` | Query | Tidak | datetime | Waktu mulai maksimum dalam format ISO 8601 dan harus di-URL-encode. |
  | `page` | Query | Tidak | integer | Nomor halaman. Default `1`. |
  | `per_page` | Query | Tidak | integer | Data per halaman, `1–100`. Default `25`. |

  ### Contoh request

  ```bash
  curl -X GET "https://app.indolat.com/api/v1/exams?search=Tes%20Masuk&is_active=true&page=1&per_page=25" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json"
  ```

<Accordion title="GET /exams/{exam}/registration-link — Link pendaftaran mandiri">
  Membutuhkan add-on **Halaman Pendaftaran Ujian dan Pembayaran Otomatis**. Jika add-on tidak aktif, permintaan ditolak dengan status `403`. Link yang dikembalikan adalah link pendek yang mengarah ke halaman pendaftaran mandiri ujian.

  ### Parameter

  | Nama | Lokasi | Wajib | Tipe | Keterangan |
  | --- | --- | --: | --- | --- |
  | `exam` | Path | Ya | integer | ID ujian. |

  ### Contoh request

  ```bash
  curl -X GET "https://app.indolat.com/api/v1/exams/12/registration-link" \
    -H "Authorization: Bearer <API_KEY>" \
    -H "Accept: application/json"
  ```

  ### Contoh response

  ```json
  {
    "success": true,
    "message": null,
    "data": {
      "exam_id": 12,
      "registration_url": "https://app.indolat.com/link/aB3xZ"
    }
  }
  ```
</Accordion>
